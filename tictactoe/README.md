# Real-Time Tic-Tac-Toe Arena (Frontend Client)

This folder contains the React 18 + Vite frontend for the anonymous real-time multiplayer Tic-Tac-Toe application.

For the comprehensive technical architecture documentation, sequence diagrams, matchmaking logic, and API protocols, please refer to the main repository [README.md](../README.md).

## Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build production bundle
npm run build
```
